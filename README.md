## File da aggiungere manualmente

1. **Foto personale:** inserisci la tua foto in `assets/img/profile.jpg` (consigliato formato quadrato, es. 600x600 px).
2. **Curriculum PDF:** inserisci il tuo CV in `assets/cv/Aldo-Dishani-CV.pdf`. Su GitHub Pages (HTTP/HTTPS) il download si attiva automaticamente; se testi aprendo `index.html` in locale con `file://`, imposta `data-cv-ready="true"` sul link `#download-cv-btn` in `index.html`.
3. **Screenshot reali dei progetti (opzionale):** inserisci le immagini nella cartella `assets/img/projects/` con questi nomi:
   - `our-team.png`
   - `prezzo-biglietto.png`
   - `cicli-js.png`
   - `js-variabili.png`
   - `index-html.png`

## Pubblicazione su GitHub Pages

1. Carica tutti i file del progetto in un repository su GitHub (ad esempio `dishanialdo.github.io` oppure `personal-portfolio`).
2. Vai su **Settings → Pages** nel repository GitHub.
3. In **Build and deployment → Source**, seleziona **Deploy from a branch**.
4. Scegli il branch `main` e la cartella `/ (root)`, quindi salva.
5. Dopo pochi secondi il sito sarà online all'URL generato da GitHub Pages.
